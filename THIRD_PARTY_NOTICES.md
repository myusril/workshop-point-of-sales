## Build-only tools (not distributed)

`lightningcss` and `axe-core` are MPL-2.0 and are used only at build/lint time.
`@axe-core/playwright` is an MPL-2.0 dev dependency used by the accessibility
tests. No MPL source or binary is copied into the runtime image; the web
Dockerfile removes the optional `sharp`/libvips payload and fails the build if it
reappears. These tools are recorded in `docs/ops/license-inventory.md`.

---

## Thermal printing

Direct ESC/POS printing uses a project-owned Android Bluetooth SPP module
(`apps/mobile/modules/escpos-bluetooth`). It links no vendor SDK. The Epson
ePOS SDK remains **REVIEW** and is not installed; share and PDF remain the
fallback.
